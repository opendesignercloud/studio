How it works

  1. Choose what the code should contain, and fill in the details.
  2. Pick colours and a style. The preview updates as you go.
  3. Download a PNG for documents and screens, or an SVG for print and any size without blurring.

Do these QR codes expire, and are scans tracked?

No. These are static codes: the information is stored inside the code itself, so it works for as long as the code exists. The code does not point to a redirect on our site, and we cannot see or count scans.

How do I make sure it scans?

  • Keep the code dark on a light, plain background. Strong contrast matters more than any style.
  • Leave the quiet zone (the blank border) alone, and print it at least 2 cm wide.
  • Rounded and dot styles look good and scan well on modern phones, but test with a couple of devices before you print a lot.
  • Logos and low contrast reduce reliability. Test again after any change.

Is what I type uploaded?

No. The code is made by your own browser, and the text, passwords and logos you enter never leave your device. To understand how the tools are used, we keep cookie-free page-view counts and simple usage counts (which tool ran and whether it worked). We never see what is inside your codes.

What does error correction do?

A QR code carries extra data so it can still be read if part of it is dirty, scratched or covered. Medium (15%) suits most uses. Choose High if you add a logo or the code will be printed on a rough surface.
